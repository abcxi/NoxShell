# 性能与安全说明

## 未发布：远程 Linux 软件安装

- 底部入口绑定当前分屏的 `SshSession`，使用已有 SSH 的独立管理通道，不走 Agent、不新建 SSH、不往 Shell/vi/密码提示注入命令。查询、生成计划和任务状态读取沿用单任务槽；同一窗口不重叠请求。关闭只按匹配的请求编号取消只读查询，不误取消其他窗口/新连接的任务。
- 支持 APT 与 DNF/YUM；默认常用包、搜索最多 50 项，单次安装 1–10 项。只查询既有缓存，不自动更新源或搜索全盘。查询子进程为非 Shell 参数数组，4 秒（安装状态检测 3 秒）限时、512 KiB 输出上限；超限标记不完整或拒绝继续。包名严格限制、拒绝选项、路径、表达式和末尾 +/- 的安装/卸载语义；计划校验仓库确实存在该精确包名，执行前再校验管理器与命令摘要。
- root 安装、非 root 仅查询，不 sudo、不索取密码。用户必须确认目标身份和完整命令，取消、切换服务器、隐藏窗口、计划异常或通道繁忙均不排队执行旧计划。APT 使用 no-remove、无交互配置保留和锁等待 0；DNF 不开放 allowerasing、启用签名检查选项、弱依赖关闭和遇锁退出。不会关闭签名验证或自动移除锁；已有仓库/系统配置仍由管理员负责，yum 的行为以目标发行版为准。
- 已确认安装通过双重 fork/独立会话启动后台监督进程，启动 RPC 立即返回，包管理器不套用只读工具的 14/18 秒超时或“取消”杀进程逻辑。降低后台进程优先级，持续排空输出，尾部日志限 32 KiB；日志磁盘写入失败仍继续读取，避免因主动关闭管道打断安装。安装自身仍有资源占用、依赖变更和维护脚本重启服务的风险，不限制到可能破坏包事务的硬 CPU/内存上限，不保证系统策略、重启或异常下永不打断。
- 每个任务独立随机 128 位编号；`/tmp/noxshell-install-<id>` 创建失败不复用、不覆盖，目录 0700、记录 0600，按目录 FD 读写、拒绝符号链接和非普通文件，并检查所有者/大小。状态核对监督进程 PID 与启动时间，失联显示未知而不是假报取消/成功；不自动重试。远端有限日志保留供排障，系统可能清理；本地 QSettings 仅保存按连接身份哈希隔离的任务编号，关闭/重开仅查询，不自动重新安装。清除本地引用需单独警告确认，不杀进程、不删除远端记录。
- 回归仅使用合成包数据、模拟 SSH 回包和临时 Python 输出进程，未运行真实包管理器安装、访问真实服务器或改变本机软件。真实发行版包源/插件兼容性仍需在目标环境验证。

## 未发布：终端定位与长命令块

- 普通 Shell 的 Alt/Option 左右键发送 Readline 的 Escape+b/f；备用屏幕或应用光标模式发送带 Alt 修饰的方向键序列，不注入 vi 的普通字母命令。组字期间不移动远端光标。

- 命令块提示符索引在输出、历史裁剪或网格重排后失效，静止输出上的鼠标移动只做二分定位；索引受终端已有最多 10,000 行历史上限约束，vi 不构建索引。移除旧 256 行命令块长度限制，图片仍限制前 300 行，并增加 32 MiB 像素内存上限；不修改远端 Shell 配置。

## v0.2.84 Linux 服务器工具

- 仅显式打开工具页时查询，自动刷新默认关闭；可选 5 秒刷新，不并行堆积。独立 exec 通道采用非阻塞状态机，单会话一个任务，运行期间暂缓普通指标采样并串行处理其他后台操作，终端收发不停止。目录扫描/传输/其他查询繁忙时拒绝排入新的管理任务。
- Python helper 在远端低优先级运行，内存地址空间限 256 MiB、CPU 软/硬限 5/6 秒、墙钟 12 秒；子命令额外使用 GNU timeout，逐块读取、按字节及时间截断。stdin EOF、取消或断开时清理自己启动的子进程，不安装守护程序、抓包/BPF/防火墙规则或临时文件。客户端最多接收 256 KiB，界面只插入设定的行数。
- 若 libssh2 OPEN/EXEC/CLOSE 完全失去响应，18 秒后断开失去响应的会话以释放资源；不承诺网络或内核异常时绝对零延迟。已有阻塞的后台操作仍需完成或超时。查询与主动测速都会产生一定 CPU、内核/网络开销，不承诺服务器零负载。
- 进程扫描最多 10000 条，显示最多 500 行，不读取 cmdline。信号只允许 TERM/KILL/STOP/CONT，确认后用 pidfd 及启动时间复核；保护 PID 1/2、内核线程、init/systemd/sshd 及 helper 的祖先链。不支持 pidfd 时拒绝有复用风险的替代操作，不自动 sudo，不越过服务器权限。
- 测速只支持用户提供的 iperf3 目标，默认目标速率 10 Mbps、3 秒、单路 TCP，允许设置的目标最高 50 Mbps。这是 iperf3 的软件 pacing 目标，不是网卡级硬限流，可能有短时突发；不要对不可信的反向测速服务端作严格限流假设。绑定地址需重新确认仍属于服务器；失效不悄悄回退默认路由。客户端/目标都需要相应工具；不自动部署测速服务或更改路由/监听端口。
- 流量仅按监听端口识别入站 TCP 已建立连接，排除回环；两次 ss/TCP_INFO 计数估算每个对端 IP 的速率，不含 UDP、转发、已结束的短连接或真实 HTTP 用户身份，代理后为 TCP 对端地址。默认 Top 10，最多 Top 100；单快照最多 4 MiB / 10000 行，监听端口最多 4096 行。超限提示不完整，不将未测到流量当作零，不声称完整排名/计费统计。
- 本地验证使用合成数据、模拟 PID 句柄和仅监听 127.0.0.1 的 SSH fixture，不对用户真实服务器发信号、测速或安装工具。实际 Linux 内核/iproute2/iperf3 兼容性仍需在目标环境验证。

## v0.2.62 的采样策略

仅当前选中且已连接的会话自动采样，不增加 SSH 连接，不部署远端守护进程。
监控仍有少量 CPU/SSH 开销，不能保证服务器完全零负载。

| 内容 | 前台间隔 | 降低开销的方式 |
| --- | --- | --- |
| CPU、内存、负载、运行时间、网卡 | 1 秒 | 优先用一个 awk 读取 /proc，缺少 awk 时兼容原有基础命令；核心数从 /proc/stat 推导 |
| CPU/内存进程排行 | 5 秒 | 两个排行都保留，不再每秒重复执行两次 ps |
| 磁盘占用 | 30 秒 | 仅本地文件系统，避免 df 触碰卡住的网络挂载 |

后台、最小化或隐藏监控区域时，基础指标间隔为 5 秒。慢速指标在未到刷新时间时保留最近结果，
并不代表其值是当前这一秒的实时读数。采样失败时按 2、4、8、16、30 秒退避；恢复成功后返回正常间隔。
同一会话不堆积并行采样；同一路径已有未完成目录请求时合并请求，完成后仍可主动刷新。
切回已有标签先显示该会话的最近采样及原始采样时间，不为填补界面空白突发追加远端查询。

按每秒请求、持续 60 秒的调度测试，进程排行采集由 60 轮降为 12 轮，磁盘由 60 次降为 2 次。
这代表命令频次降低约 80% 和 96.7%，**不是服务器 CPU 占用降低比例**。

采样数据最多 512 KiB，读取受超时及取消约束。终端搜索输出刷新最多每 100 毫秒一次，
搜索词变更与前后跳转即时处理；不丢弃终端数据来伪造流畅。

## 凭据与连接

macOS 读写通过 Security 框架操作 Keychain，不把编码后的密码放入子进程命令行。
v0.2.66 在 v0.2.65 移除 `security` 读取兼容路径的基础上，彻底移除授权模式，全部原生操作禁止交互。
沿用既有 `com.noxshell.ops.ssh` 服务名及序列化格式，不批量迁移或删除条目。
不可读的旧条目由用户重新输入 SSH 凭据；成功认证后按用户选择保存为新条目并更新引用。
不会降级到明文存储，也不会把其他条目的凭据拿来尝试。

会话公开元数据不保留密码/私钥口令，worker 在认证结束或清理连接时释放相应副本。
这不意味着可以保证所有内存、交换区或系统库中的历史副本已被安全擦除。
未知指纹仍需用户确认，已知指纹变化仍阻断；不自动重放失败命令，不降低 SSH 算法安全性。
